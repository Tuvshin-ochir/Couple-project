> Фонт: Prata (гарчиг), Onest (текст), Bad Script (гар бичмэл) — гурвуулаа монгол Ө, Ү үсэгтэй.

## Ажиллуулах

```bash
npm install          # хамаарлууд + Prisma Client үүсгэнэ
cp .env.example .env # SESSION_SECRET-ийг бөглөнө (доорх тайлбарыг үз)
npx prisma migrate deploy
npm run dev          # http://localhost:3001
```

`SESSION_SECRET` үүсгэх:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

Анх нээхэд `/setup` хуудас гарна — хоёулангийн нэр, "чи аль нь вэ", хосын нууц үгийг оруулна.
Хайрт нь `/login` хуудсаар өөрийгөө сонгоод мөн нууц үгээр нэвтэрнэ.

## Командууд

| Команд | Үйлдэл |
| --- | --- |
| `npm run dev` | Хөгжүүлэлтийн сервер, порт 3001 |
| `npm run build && npm start` | Production горим, порт 3001 |
| `npm run db:migrate` | Schema өөрчилсний дараа шинэ migration үүсгэнэ |
| `npm run db:studio` | Өгөгдлийг Prisma Studio-оор харах |

## Интернэтэд байршуулах

Хоёулаа өөр өөр газраас орохын тулд сайтыг интернэтэд гаргах хэрэгтэй.
SQLite нь файл тул **байнгын диск**тэй сервер шаардлагатай (VPS, Railway volume, Fly.io volume г.м.).

1. Сервер дээр `.env`-д шинэ `SESSION_SECRET` тавина.
2. `npm ci && npx prisma migrate deploy && npm run build && npm start`
3. HTTPS-тэй домэйн холбоно (production горимд cookie зөвхөн HTTPS-ээр явна).

Vercel зэрэг serverless орчинд байршуулах бол `prisma/schema.prisma`-д `provider = "postgresql"`
болгож, `@prisma/adapter-pg` адаптер ашиглан Neon/Supabase зэрэг Postgres сан холбоно.

> Нөөц: `prisma/dev.db` файлыг хуулж хадгалах эсвэл Тохиргоо → "Нөөц татах" (Нууц өрөөний зураг нөөц файлд ордоггүй — зөвхөн `dev.db`-д бий).

> ⚠️ Desktop хавтас iCloud-д синк хийгддэг бол `.next/`, `src/generated/` дотор "файл 2.ts" гэх мэт давхар файл үүсч болно. Төслийг iCloud-гүй хавтас руу (жишээ нь `~/Projects`) зөөх нь найдвартай.
